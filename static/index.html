Quick Start
1
Install prereqs + configure env
cd ctib cp .env.example .env # set GEMINI_API_KEY pip install -e .
2
Spin up HAPI FHIR + seed patient data
docker compose up -d python seed_fhir.py # seeds 97 FHIR resources
3
Launch CTIB
python main.py # Dashboard → localhost:9000 # Docs → localhost:9000/docs python -m pytest tests/ -v
